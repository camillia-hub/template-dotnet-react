# Architecture decision records

Decisions that change structure, technology or cross-cutting behavior are recorded
here as ADRs — one file per decision: `NNNN-short-title.md`.

## Format

```md
# ADR-NNNN: <title>

- Status: proposed | accepted | superseded by ADR-XXXX
- Date: YYYY-MM-DD

## Context
What forces the decision.

## Decision
What was decided.

## Consequences
What becomes easier, what becomes harder.
```
